# Meanwhile

An interactive comparison engine for human history. Choose a date, compare what was happening across five broad world regions, filter by theme, and switch between a timeline and a map.

This first version is deliberately compact and runs as a static site with plain HTML, CSS and JavaScript. The map uses Leaflet and OpenStreetMap.

## Run locally

Open `index.html` directly, or serve the folder with any simple static web server.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)**.
